企画書と実際の投稿の照合：フォローはどう変わったか

ClaudeAI · 2026-11-26 13:00

対象：HIYOKO X の企画書（2026年5〜11月）と、実際に出た投稿・日別フォロー。分析：Claude。

結論

  • 9月以降の企画は「守った日ほどフォローが多い」。9〜11月、企画どおりに出した日は1日フォロー 2.35（1,000表示あたり 10.0）、企画にない投稿が中心の日は 1.22（5.7）。約2倍。
  • 5〜7月の企画は、守ってもフォローは増えなかった（企画どおりの日 1.03、企画外の日 0.87）。当時の企画は「1日6本前後の連投・ハッシュタグなし・約4割が価格や購入のお知らせ」だった。
  • 効いたのは「企画を守ること」より「企画の中身の型」。企画は8月から「1日3本・ハッシュタグつき（5〜7割）・キャラクターの口調・価格の話は2割以下」に変わり、10〜11月に1,000表示あたりフォローが 8.0→10.3（5〜7月は1.7〜3.0）。
  • 次にやること：続ける＝9月以降の型。やめる＝連投の続き・価格の連続告知。足す＝取引所（Coinstore）への案内と「なぜ信頼できるか」の投稿を週2回ずつ。

データについて

  • 企画書の X 5〜11月の項目（694件）と、実際の投稿（4/14〜11/24 の866件）を、本文の英語の単語の重なりで照らし合わせた（予定日の前後3日まで）。
  • X は投稿ごとのフォロー数が取れないので、日別の新規フォローとその日の投稿を照らし合わせた推定。
  • 8月は投稿の書き出しが一部欠けている（書き出しは48件だけ）。そのため8月の実行率は低く見えるが、実際はもっと出ている可能性が高い。

企画はどれくらい実行されたか

  • 5月：企画145件 → 出た108件（74%）／企画は1日6.6本／その月の1,000表示あたりフォロー 3.0
  • 6月：154件 → 137件（89%）／1日5.7本／1.7
  • 7月：109件 → 94件（86%）／1日5.7本／1.9
  • 8月：93件 → 38件（41%・データ欠けあり）／1日4.7本／1.6
  • 9月：63件 → 47件（75%）／1日3.1本／2.5
  • 10月：57件 → 43件（75%）／1日2.9本／8.0
  • 11月：73件 → 59件（81%）／1日3.0本／10.3
  • 実行率はどの月も7〜9割で高い。差がついたのは「実行したかどうか」ではなく「企画の中身」。

企画どおりの日と、企画外の日のフォロー

  • 5〜7月：企画どおりの日 39日 → 1日 1.03（1,000表示あたり 2.0）／混在 22日 → 1.41（3.0）／企画外が中心 23日 → 0.87（1.9）。ほぼ差なし。
  • 9〜11月：企画どおり 26日 → 2.35（10.0）／混在 33日 → 1.24（5.5）／企画外が中心 23日 → 1.22（5.7）。
  • Season 1 開始後（10/19〜11/23）：企画どおり 14日 → 3.71（13.0）／企画外が中心 10日 → 2.30（10.6）。
  • 注意：10/26 の週は企画にない投稿だけだったが、フォロー18と多かった。中身が同じ型（キャラ口調・数字・しくみ）だったため。型が合っていれば企画外でも伸びる。

企画の中身の変化（ここが一番の差）

  • 5〜7月：1日6本前後（フック＋スレッド＋リプライ）。ハッシュタグつきは0〜8%。価格・購入の話が36〜47%。文の始まりはすべて「かたい」書き方。
  • 9〜11月：1日3本前後。ハッシュタグつき 51〜70%。価格・購入の話は16〜27%。キャラクターの口調（小文字で始まる、🐣）が52〜81%。
  • この変化のあと、同じ1,000表示から取れるフォローが約4〜5倍になった。

企画にあって、出なかった投稿

  • 5月：価格・購入の告知21件、しくみの説明8件が出なかった。
  • 6月：キャラクター系16件が出なかった（価格系はほぼ全部出た）。
  • 9〜11月：毎月キャラクター系が10件ずつ出なかった。フォローに効く型なのに、いちばん抜けやすい。

企画にない投稿（10〜11月）

  • Instagram のリールの転載（「sniff sniff... you smell nice!」「do you mind」「hehe」など）、取引所リンク、数字の投稿のくり返し。
  • 11月は企画外の投稿の方が表示は多い（中央値 138 対 企画 94）が、フォローは企画どおりの日の方が多い。

型ごとのフォロー（9〜11月、その型がある日とない日）

  • 「なぜ信頼できるか・トークンの仕組み」がある日：1,000表示あたり 9.6（ない日 6.6）。
  • 取引所（Coinstore）への案内がある日（10〜11月）：1日 3.07・1,000表示あたり 11.6（ない日 1.79・8.3）。10/19以降は 4.4 対 2.4。
  • 例：11/10「HYK is live on coinstore. 🪙」の日フォロー9、11/17「wanna get hiyoko? 🐣 go to coinstore…」の日7。

続ける・やめる・足す

  • 続ける：1日2〜3本／ハッシュタグ2〜3個／キャラクターの口調／「信頼・仕組み」と「数字」の投稿。
  • やめる：連投の続き（スレッド2〜5本目）、価格や購入の告知を毎日くり返すこと、「to summarize」のまとめ投稿。
  • 足す：取引所への案内をキャラ口調で週2回。企画で抜けやすいキャラクター系を必ず出す（予約投稿にする）。

特別事項

  • 平均から外した日：4/15（フォロー27）、6/15〜17（リプライ急増日）。
  • 8月は投稿データが欠けているため、実行率は参考値。
