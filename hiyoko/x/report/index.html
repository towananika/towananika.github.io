【調査予定】10〜11月 インプレッション再上昇の要因を探る 2026-11-25 ・ 初期レポート

9月（中央値72）→10月（75）→11月（105.5）と段階的に上昇。Season 1 開始やタグ復活との関連を調査中。

根拠（実測）

  • 2026-09: 中央値 72.0（8月29.5から+144%）
  • 2026-10: 中央値 75.0、新規FW +181%（前月比）
  • 2026-11: 中央値 105.5（2026年6月以降で最高）
  • 2026-10: URLクリック -44%（リンク投稿が減少）
  • 2026-10: タグ平均 2.0個（7月のタグなし93%から大幅回復）

可能性・仮説（調査対象）

  • Season 1 開始によるコンテンツ転換の効果か
  • タグ復活→新規リーチが増加した可能性
  • 投稿頻度の適正化（大量連投の抑制）の効果か
  • ゲーム・Happy Chick テーマの比率変化との相関
7月 インプレッション急減（中央値 −43%）の要因分析 2026-11-25 ・ 初期レポート

6月（中央値60）→7月（中央値34）に急落。158件投稿したにもかかわらずエンゲージメントがほぼ消滅した月。

根拠（実測）

  • 6月→7月: 中央値 60→34（-43%）
  • 7月: rp≥2 の投稿が0件（158件中）
  • 6/30〜 1日8本以上の連投が始まった
  • 7月: タグなし投稿が全体の93%
  • 7月 保存合計: 4件（6月比で大幅減少）

可能性・仮説

  • 大量連投による希薄化: 1日8本以上投稿すると各投稿のリーチが分散しアルゴリズム的に不利になる可能性がある（因果未確認）
  • タグなし投稿の増加: 新規ユーザーの発見経路が減少した可能性
  • 上場特需後の流入消滅: 5〜6月の「上場」関連の外部リプ流入が自然減した可能性（外部要因）
  • コンテンツ制作時間の短縮: 大量投稿に伴い個々の制作時間が減少した可能性

データの制約

  • 7月のCSVは97件のみ収録（158件投稿のうち）。残り61件のKPIは不明。
4〜5月 インプレッション急増の要因調査（6つの可能性） 2026-11-25 ・ 初期レポート

アカウント全体表示は3月（9,621）→4月（19,223）でちょうど2倍に急増し、5月も17,269と高水準を維持しました。ただし「なぜ増えたのか」を詳細に分解すると、4月のスパイク型急増と5月の底上げ型維持では性質が異なります。

1. 根拠（実測KPIの事実）

  • いいね数は増えていない：アカウント全体のいいねは 3月 876 → 4月 734 → 5月 721 と微減。増えたのは 表示数（2倍）・プロフ訪問（3月144→4月307）・返信（166→221）。
  • 4月は4/15〜17に極端集中：4/15単日だけで表示 2,405・新規フォロー 27（月間72の38%）・プロフ訪問 49・返信 46 を記録。一方、4/20〜22の中央値は 33〜35 に戻っている。
  • 5月は外れ値を除いても全体が底上げ：300 imp超のスパイク投稿を除外した中央値も 4月 72.5 → 5月 92.0（6月は58.0）へ上昇。5/08以降は週別中央値が 94〜110 で安定。
  • 形式シフト（5月）：「リスト/図解」が4月 12件 → 5月 48件（中央値 117.5） へ4倍増し、保存合計も 4月46件 → 5月124件へ増加。

2. 考えられる6つの可能性

  • ① ボット／自動応答による露出・返信の押し上げ（可能性高）
    いいね数が横ばい〜微減なのに表示数と返信だけ急増している点、また4/15や5/23の突出投稿でWeb3セール系ワードを含む投稿だけ異常値が出ている点から、ボットがリプライ・クロールして見かけの表示数を押し上げた可能性が高い。
    x.com/HiyokoGlobal/status/2044325153182756934 ↗
    x.com/HiyokoGlobal/status/2058110698778247442 ↗
  • ② プレセール開始＋上場予定発表による外部検索・駆け込み需要
    4/15〜17に「Presale is active」「Listing planned mid-to-late May」「Vesting」「MetaMask手順」を集中投下し、5月下旬は「来週がラストスパート（最安値 $0.015）」としてプロフ訪問が増えた可能性。
  • ③ インドネシアKOLマーケティングによる現地流入
    4/15の投稿本文に 🇮🇩 KOL marketing in Indonesia is active や 🇮🇩 Indonesia's community と明記されており、同日の新規フォロー27件・表示2,405はKOL施策からの流入と重なる可能性がある。
  • ④ 「リスト／図解」形式へのシフトによる実力ベースの底上げ（5月）
    5月は「リスト/図解」を48件（中央値117.5）投入し、HYK's 4 use cases やロードマップなど一目でわかる投稿が増えたため、スパイクを除いた通常投稿の中央値も92.0まで底上げされた可能性。
  • ⑤ 4/1〜4/13の未収録期間における別要因
    4月のアカウント全体表示 19,223 のうち、4/14以降の投稿別CSV収録分は 5,403 のみ。差分の約13,820表示は4/1〜13の投稿や投稿外インプレッションによるもので、前半に別の拡散要因があった可能性もある。
  • ⑥ プロフ訪問増による固定投稿・過去投稿への連鎖閲覧
    4月にプロフ訪問が307件（3月の2.1倍）に増えたことで、プロフィール上の固定投稿（2/11）や他投稿への回遊が増え、アカウント全体の表示数が増えた可能性。

3. 個別投稿の違和感ポイント

  • 4/15投稿（415 imp）：同日スレッド的5本のうち最初の3本は71〜83 imp・いいね2・返信1だったのに4本目だけ415 imp・返信4に突出。
  • 5/23投稿（743 imp・全期間1位）：同内容の5/09（187 imp）・5/11（201 imp）といいね数は大差ない（9 vs 6〜8）のに表示数だけ約4倍・ER 5.9%へ低下し、presale.hiyoko.io 記載にも関わらずURLクリックは0件。

データの制約

  • 4/1〜4/13および3月の投稿別CSVが欠損しているため、4月前半の投稿別内訳は確認できていません。
  • ボット判定はCSVの数値挙動からの推測であり、当時のリプライアカウント精査が別途必要です。
X コンテンツ4グループのボード（A〜D分類） 2026-11-19 ・ 初期レポート

対象：@HiyokoGlobal の投稿 359件（2026年7月2日〜11月19日）
全投稿を「見られたか（同じ月の中央値以上か）」×「プロフィールまで来たか（訪問1回以上）」で4つに分類。

4グループの整理

  • A（見られて、来る｜70件）：この型をそのまま増やす（悩み→解決シリーズや解説記事など）
  • B（見られるが、素通り｜112件）：本文の最後に「HIYOKO公式で見る」等を1行足す
  • C（見られないが、来る｜30件）：中身は効いているが露出不足。書き直して再投稿
  • D（届かない｜147件）：リンクだけ・一言だけの投稿はやめる

グループを分ける主な要因

  • ハッシュタグあり投稿は35〜38%がA、タグなしは11%がA（多くがD）
  • 1日2本の日は38%がA、6本以上の日はAが9%まで低下
  • リンクだけの投稿は94%がDまたはB

X 「悩み→解決」シリーズの企画 2026-11-19 ・ 初期レポート

Xでプロフィール訪問とフォローを生んでいるのは、NFT・アイテム所有のテーマを「読み手の悩み」から書いた投稿。

根拠（実測）

  • 悩みから入った投稿（11/9）：1,000表示あたりプロフィール訪問 40（全体平均は6.8）
  • NFTの機能説明から入った投稿（8/28・9/17）：訪問 0
  • リンクだけのNFT投稿（11/15）：表示 25・訪問 0

投稿の型（5ステップ）

  • 1. 悩み：「you」が主語の1行（例：ゲームがサ終してアイテムが消える）
  • 2. ひっくり返す：なぜそうなるのかを1行
  • 3. 答え：HIYOKOの事実を1つだけ（専門用語は言い換える）
  • 4. 質問：答えたくなる問いで締める
  • 5. タグ：3つ（#HIYOKO＋テーマ＋流行タグ）

※ 本文は60〜200字。リンクは本文に入れず返信欄か固定ポストに置く。
