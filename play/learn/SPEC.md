# 二水の学び場 — 体験仕様

## 一行の意図

二水の小さな出来事を通して、現実にも持ち帰れる「観察・比べる・確かめる」を5分で練習する。

## この版でできること

- 3つの短い出来事を読み、選択肢で考える。
- 正誤だけでなく、判断の理由を読む。
- 最後に今日の学びを振り返る。
- 進行は端末内に保存する。

## 完了条件

1. 初回画面から学習を始められる。
2. 各問いは1度だけ答えられ、理由を読んで次へ進める。
3. 3問後に振り返りが出る。
4. `node play/learn/engine.test.cjs` が状態遷移を検証する。

## 追加の順番

次は一教科だけを足す。候補は、経済の「需要と選択」または歴史の「資料を読む」。単に問題数を増やさず、覚えた知識を使う小さな場面を先に作る。
